Deze module maakt deel uit van het Meetnet Biodiversiteit Agrarisch Gebied (MBAG). INBO zal in samenwerking met VMM een set van meetpunten langs waterlopen opvolgen. We meten hiervoor de biotische kwaliteit via macro-invertebraten en linken dit aan metingen van de waterkwaliteit en kenmerken van het afstroomgebied. De meetpunten zijn geselecteerd om middelgrote afstroomgebieden te vertegenwoordigen die gekenmerkt worden door ofwel landbouw op lichte gronden met dominantie van maïsteelt ofwel landbouw op zwaardere gronden met dominantie van graanteelt.
